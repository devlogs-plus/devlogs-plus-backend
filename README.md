# Devlogs+
Share devlogs, commits, and time spent on a project with the world.

## Features
* Projects
   * Make projects
   * Share projects
   * Add devlogs to projects
* Wakatime support
   * Link your wakatime/hackatime account
   * Add wakatime projects to your projects
   * Add time spent to a devlog
* Git support
   * Connect your Git provider
   * Add git repositories
   * Choose git commits that have been spent for the project
* Social Features
   * Have a feed generated for you with devlogs and projects
   * Follow people to get email updates
   * Choose topics you like.
